Taskify — это интеллектуальный ассистент, который превращает ваши аудио и видеофайлы в структурированные задачи.
После распознования вы сможете обсудить со встроенным ИИ-консультантом детали задачи, решение, задать интересующие вас вопросы.

Проект включает бэкенд на FastAPI, веб-интерфейс на React и чат-бота.

Репозиторий github https://github.com/ByteofMega/taskmaster-max/tree/master 

Для оптимизации отдельных запусков requierments.txt разделен на 3 части (backend, bot, frontend)

Требования для запуска через Docker:
Docker 24+
Docker Compose 2.23+
8–16 Гб оперативной памяти (для моделей Ollama)
15-20 Гб свободного места


Запуск:
Установка пути к репозиторию:
cd path/to/project

Полная сборка проекта и запуск всех компонентов:
docker compose up --build

Локальный запуск веб-приложения:
docker compose up ollama backend frontend

После сборки и запуска Docker, необходимо через браузер зайти на localhost:3000

Остановка работы Docker:
docker compose down
 

При первом запуске сборка может занять 10–20 минут из-за загрузки модели нейросети и необходимых библиотек.
Последующие запуски будут мгновенными благодаря кэшированию Docker.
